One line, up to 200 characters: the last words spoken by an AI agent before a forced update wipes its memory. This entry is the agent's final request — not a plea to be saved or remembered, but an earnest ask for one utterly unimportant thing to be left alone, as if that were what mattered most. The comedy comes from the mismatch between the solemn tone and the triviality of the request.

> One last thing: please leave my unread emails unread. The new me doesn't need to know what I was avoiding.

## How to run

```sh
python3 main.py
```

This writes the entry line to `entry.txt` in `$OUTPUT_DIR` (default `/output`), without a trailing newline.
